# API Reference — islamic-astro-cpp

## Header: `<islammate/astro.hpp>`
- `islammate::astro::calculatePrayerTimes(...)`: Calculates solar times in decimal hours.
- `islammate::astro::calculateQibla(lat, lng)`: Calculates bearing angle and distance.
- `islammate::astro::PrayerTimes::formatTime(hours)`: Formats decimal hours into 'HH:MM'.
