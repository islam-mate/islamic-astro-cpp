# Getting Started Guide — islamic-astro-cpp

Welcome to **islamic-astro-cpp**, maintained by the [Islam Mate Community](https://github.com/islam-mate).

## Architecture & Design Goals
- **Zero or minimal dependencies**: Pure idiomatic code tailored for its host ecosystem.
- **Offline first**: Computes astronomical values and handles data without remote API dependency.
- **Type-Safe**: Full types and documentation for robust production systems.
